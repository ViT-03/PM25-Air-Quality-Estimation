# PM2.5 Air Quality Estimation

This project implements a machine learning pipeline to estimate PM2.5 levels using a multi-modal approach. It combines images (extracting visual features and applying Dark Channel Prior - DCP) with meteorological data to predict air quality.

## Repository Structure
Based on the project organization, the repository is divided into:
* **`data/`**: Contains the original dataset and processed data. Please read `README_DATA.md` for instructions on data configuration.
* **`src/`**: Contains scripts for data preprocessing, enrichment, and generating folds for cross-validation.
* **`experiments/`**: Contains the training and validation scripts for the various model versions.

## Execution Pipeline

### 1. Data Preparation
Navigate to the root directory and prepare the dataset using the scripts in `src/`:
1. **(Optional) Run `prepare_dataset.py`**: This enriches the separate `train` and `test` splits by downloading historical weather data from the Open-Meteo API and calculating DCP (Dark Channel Prior) features.
2. **Run `create_kfold.py`**: This is the core data script for the cross-validation pipeline. It merges the original train and test sets, generates the weather and DCP features for the unified dataset, copies the images, and maps assignments for a 5-Fold Stratified Cross-Validation. The final output is stored in the `NewDataset/` folder.

### 2. Model Training
The project includes three different architectural iterations trained on `NewDataset`. Each features 4 ablation configurations (Base, Base+DCP, Base+Weather, Base+Weather+DCP):
* **V2 (`train_v2_kfold.py`)**: Baseline model based on EfficientNet-B0 with a 2-phase K-Fold training (head-only followed by full fine-tuning).
* **V3 (`train_v3_convnext.py`)**: Multi-task architecture based on ConvNeXt-Tiny for feature extraction, fused (Late Fusion) with an XGBoost regressor.
* **V4 (`train_v4_final.py`)**: The final optimized pipeline improving upon V3. It introduces:
  * Hyperparameter optimization using Optuna (50 trials) for XGBoost.
  * Spatial data augmentation via **CutMix**.
  * **Test-Time Augmentation (TTA)** during feature extraction for XGBoost inference.
  * **Asymmetric L1 Loss** to heavily penalize PM2.5 underestimations.
  * **WeightedRandomSampler** for class imbalance handling and Cosine Annealing LR scheduling.
  * Saves trained models to the `ensemble_models/` directory.

### 3. Evaluation and Statistics
The training scripts output history and prediction CSVs directly in the root directory (e.g., `history_v4_base.csv`, `ablation_v4_results.csv`).
* **`ablation.py`**: Analyzes the predictions and loss curves generated by the training scripts, creating grouped bar charts, scatter plots, and error distributions, saving them in `final_ablation_files/`.
* **`statistical_test.py`**: Verifies the statistical significance of the architectural results (both intra-version and inter-version) using paired t-tests and the Wilcoxon signed-rank test on out-of-fold predictions.
